# dverzeroli3.github.io

Sito dello sviluppatore di **Perfect Drop**, pubblicato con GitHub Pages su
https://dverzeroli3.github.io/

- `index.html`: pagina dello sviluppatore (link a Google Play e all'informativa sulla privacy).
- `app-ads.txt`: file richiesto da Google AdMob sulla radice del sito indicato in Play Console.
  Si genera nel repository del gioco con `node tools/app_ads.js pub-XXXXXXXXXXXXXXXX`.
- `.nojekyll`: i file vengono pubblicati così come sono.

I file originali sono nella cartella `site/` del repository del gioco.
